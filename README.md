# Campus AutoAim

基于 **C++17、OpenCV 和 ROS2 Jazzy** 的 RoboMaster 校园赛视觉自瞄项目。

项目从传统装甲板识别逐步扩展至数字分类、位姿解算、目标选择、运动预测和云台控制，采用模块化结构组织各阶段算法。

当前实现校园赛的基础半自动流程：**底盘由操作者控制，程序负责视觉识别、目标选择、云台瞄准和开火条件判断。**

> 能量机关相关算法已移除，当前版本不包含能量机关识别与击打功能。

## 功能简介

### 装甲板检测与分类

- 使用红蓝通道色差与亮度阈值提取灯条。
- 通过轮廓面积、长宽比和倾斜角筛选灯条。
- 根据灯条长度比、方向差、间距和相对高度进行配对。
- 计算数字区域四角，通过透视变换提取数字图像。
- 使用 **HOG 特征 + SVM** 进行类别识别。
- 根据识别结果，通过工厂函数直接创建对应的 `Armor1～Armor8` 对象。

当前项目中的类别约定：

| 类别 | 对应目标 |
|---|---|
| 1～5 | 对应编号机器人 |
| 6 | 前哨站 |
| 7 | 哨兵 |
| 8 | 基地 |

### 位姿与瞄准解算

- 根据识别类别确定大小装甲板模型。
- 使用消息中的相机内参和畸变参数进行 PnP 解算。
- 输出目标相对相机的位置、距离和姿态。
- 提供相机坐标与世界参考坐标之间的转换。
- 根据目标位置和弹速解算云台 yaw、pitch，并进行重力补偿。

### 目标选择

通过两类评分分别处理目标关联和攻击优先级：

- **目标关联**：结合图像中心连续性和编号连续性，寻找上一目标。
- **攻击优先级**：主要结合距离与板面朝向评价候选目标。
- 设置切换分差，减少优先级接近时的反复切换。
- 返回首次选择、连续关联、主动切换、重新获取和无目标等状态，为预测器管理历史提供依据。

编号和当前帧下标均不作为永久物理目标 ID。

### 运动预测

- 将目标位置转换到统一世界坐标中测速。
- 利用当前云台姿态和自身位置进行旋转、平移补偿。
- 使用消息时间戳计算观测时间间隔。
- 加入过小、过大及异常时间间隔保护。
- 通过 `EMPTY / WARMUP / TRUSTED` 状态和位置残差检查保护运动历史。
- 采用匀速模型预测近似弹丸飞行时间后的目标位置。
- 预测结果参与实际瞄准；预测不可用时回退当前 PnP 位置。

### 前哨站与建筑攻击

- 根据敌方血量信息管理建筑攻击权限。
- 当前策略要求敌方 4、5 号机器人均被确认阵亡后，才允许选择前哨站。
- 前哨站被确认摧毁后，才允许选择基地。
- 前哨站采用独立圆周预测模块，区分三层装甲高度，并估计旋转方向。
- 前哨站开火增加准星位于装甲四边形内、板面侧转角不超过阈值等条件。

### 云台与战斗状态管理

- **TRACK**：有效目标存在时跟随解算角度。
- **HOLD**：短暂失去观测、选择器仍保持锁定时维持当前姿态。
- **SEARCH**：解除锁定后，根据底盘移动方向调整搜索中心。
- 搜索阶段按最短角差拒绝超过 120° 的移动方向跳变。
- 无目标持续一段时间后，执行俯仰回正。
- 无血或无弹时解除目标相关历史并禁止射击，同时保留移动方向跟随和回正功能。

## 整体处理流程

```text
订阅 /autoaim/frame
        ↓
读取图像、相机参数和机器人状态
        ↓
战斗状态与建筑攻击权限检查
        ↓
压缩图像解码
        ↓
灯条检测与配对
        ↓
ArmorCandidate
        ↓
数字区域透视变换
        ↓
HOG + SVM 分类
        ↓
创建对应 Armor 派生类
        ↓
PnP 位姿解算
        ↓
TargetSelector 目标选择
        ↓
普通目标运动预测 / 前哨站圆周预测
        ↓
AimSolver 瞄准与重力补偿
        ↓
GimbalController 跟随、保持、搜索与开火判断
        ↓
发布 SendData
```

识别结果、目标选择、位姿信息和预测点通过 OpenCV 窗口显示。


| 模块 | 主要职责 |
|---|---|
| `autoaim_node` | ROS2 通信、状态读取及各算法模块的流程衔接 |
| `armor` | 灯条、候选装甲、装甲派生类、数字结果及几何信息 |
| `detector` | 灯条提取、筛选和配对 |
| `number` | 数字区域裁剪、HOG 特征提取和 SVM 分类 |
| `pose` | 构造模型点与图像点，完成 PnP 位姿解算 |
| `target_selector` | 建筑攻击权限、目标评分、关联和切换 |
| `motion_predictor` | 世界坐标测速、运动历史保护及三维预测 |
| `aim_solver` | 坐标转换、瞄准角度与重力补偿 |
| `gimbal_controller` | TRACK、HOLD、SEARCH 和开火条件判断 |
| `outpost_aimer` | 前哨站高度分层、旋转方向估计和圆周预测 |
| `draw` | 检测、位姿、选中目标及 FPS 显示 |

## 环境与运行

主要依赖：

- ROS2 Jazzy
- C++17
- OpenCV
- `ament_cmake`
- `rclcpp`
- `ament_index_cpp`
- `sensor_msgs`
- `cv_bridge`
- 校园赛配套自定义接口包 `tdt_interface`

将 `campus_autoaim` 和配套的 `tdt_interface` 放入 ROS2 工作空间的 `src` 目录，然后执行：

```bash
source /opt/ros/jazzy/setup.bash

cd ~/campus_ws
colcon build --packages-select tdt_interface campus_autoaim

source install/setup.bash
ros2 run campus_autoaim autoaim_node
```

运行前需要启动校园赛及 ROS 通信，并选择允许 ROS 控制云台的模式。游戏和算法节点应使用一致的 `ROS_DOMAIN_ID`。

当前节点使用：

| 方向 | 话题 | 消息类型 |
|---|---|---|
| 订阅 | `/autoaim/frame` | `tdt_interface/msg/AutoAimFrame` |
| 发布，默认蓝方配置 | `/target_angles_player_1` | `tdt_interface/msg/SendData` |
| 发布，切换为攻击蓝方时 | `/target_angles_player_2` | `tdt_interface/msg/SendData` |

当前只处理 `compressed_image`，运行时加载 `model/svm_model.yml`。

## 当前限制与后续方向

- 传统阈值和几何检测仍会受到光照、过曝、遮挡及相邻目标干扰。
- 数字误识别可能进一步影响装甲尺寸选择和距离解算。
- 目标关联采用图像位置与编号连续性，无法保证始终关联同一块物理装甲板。
- 普通目标预测采用匀速模型，对急转、加速和旋转换板的适应能力有限。
- 移动瞄准和前哨站击打仍需要结合实际画面继续验证。
- 部分参数和场景常量仍集中写在源码中，尚未统一配置化。

后续优先完善识别与关联稳定性、预测效果验证和参数配置，再逐步扩展导航及作战策略。
